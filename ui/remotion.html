Durasi
60 detik untuk topik yang butuh 3 langkah penjelasan.
Pilihan lain (aplikasi suara, catatan, jenis video)
Aplikasi suara (centang yang dipakai; naskahnya dibuat untuk tiap aplikasi)
Cara kerja
  1. Tulis topik, pilih durasi dan pilihan videonya (loop, "Intip yuk!", musik, aplikasi suara).
  2. Salin brief ke Claude Code yang dibuka di folder klipian. Ia mencari web, menulis cerita, dan membuat folder videonya.
  3. Pilih folder hasilnya dan ambil ceritanya, cek setiap klaim beserta sumbernya, lalu pilih judul.
  4. Buat naskah untuk aplikasi suara, impor suaranya dan cocokkan, lihat pratinjau, lalu Render. Hasilnya masuk ke Clips, siap diunggah.

Tanpa API key: klipian bekerja di komputer ini, dan AI-nya adalah Claude Code di komputer ini.
