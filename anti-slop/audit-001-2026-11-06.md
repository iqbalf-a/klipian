# antislop UI audit 001 (2026-11-06)

Scope: every page in `ui/` (profiles, Edit home `/`, workspace, sources, remotion, guide) plus `ui/css` and `ui/js`.
Method: code greps + the live server on 5177 (profile "klipian podcast"), dark, light and 375px.
Not covered visually: the editor screens inside a project (Assets ... History). They were not opened, because
opening a project writes "last opened" into ian's real workspace. Check them on a temp copy (port 5178).

Direction: `docs/ui-design.md` (status block 2026-10-16) plus memory "klipian UI style".
Design Read: personal desktop workbench for one clipper, compact bordered controls, yellow accent, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

Recorded overrides (direction decided these; NOT findings, do not change):
Geist as the UI font, sidebar + topbar frame, gradient on the "klipian" wordmark, dark default with a working theme toggle,
pill-shaped segmented nav (a switch, not a button), loading spinners/shimmer that loop (real loading state; global
`prefers-reduced-motion` rule in app.css:981 already stops them).

Priority: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## HIGH

1. **R-25 Status colours fail contrast in light mode.** `Posted` = `oklch(.75 .16 145)` on white measured **2.09:1**.
   `Scheduled` (`oklch(.75 .14 230)`), `Ready` (accent yellow) and the Sources "transcribed" label use the same light-on-light idea.
   Fix: per-theme status tokens in `tokens.css` (dark keeps today's values; light gets darker ones), used by
   `workspace.src.css:48-52` and the sources label; rebuild `workspace.css`. Every status text >= 4.5:1 in both themes.
2. **R-03 Page overflows at narrow widths.** At 375px `/workspace` measures scrollWidth 715 vs 375 (topbar nav + profile + icons do not wrap).
   The Rendered output table loses its File column completely; the clip table shows ~8 characters of the title.
   Fix: topbar wraps (nav row below the brand under ~720px), no page-level horizontal scroll on any page; tables may scroll inside their own panel only.
   Name/title columns keep a usable min width (see 10).
3. **R-27 / R-40 Broken thumbnails on the Edit home cards.** 3 of the first 8 project cards show the browser's broken-image icon.
   `projects.js:987` renders `<img class="project-thumb loading" loading="lazy">` with no error fallback and no width/height.
   Fix: on `error`, swap to the existing `.project-thumb.empty` look with a short "No preview" text; give the img width/height (or aspect-ratio).
4. **R-02 Em dash in user-visible text (~40 places).** Page titles (`klipian — workspace`, 5 pages), `index.html:307,463,815,821`,
   toasts/errors/tooltips in `js/editor/*` (analysis 114, app 394, 442-445, assets 328/430/489/515, bulk 482/507, compose 341/413/443,
   framing 839/847/1339, projects 150, result 788, timeline 313), `shared/topbar.js:41-42`, `shared/ytdl.js:181`,
   `workspace/clips.js` (230, 274, 275, 350, 371, 410, 479, 577, 1051, 1225, 1228), `workspace/render.js:50`, `workspace/sources.js:91`.
   Fix: colon, comma, period or parentheses. Empty-value cells that print `"—"` (`helpers.js:30`, `sources.js:21,88`,
   `projects.js:919`, `framing.js:618`) become an empty cell. Code comments are exempt. Tests that assert these strings change with them.
   Run: `grep -n "—" ui/*.html ui/js/*/*.js` and leave only comments.
5. **R-32 Caption word input has no focus indicator.** `.word-input` (`app.css:2350`) sets `border: 0; outline: none` with nothing in its place.
   Fix: a visible `:focus-visible` style (accent underline or 1px accent border). While there, confirm the other `outline: none` rules
   (`.paste`, `.result-select`, `.asset-select`, `.result-trigger`, `.rec-time-in`, `.time-input input`) show a border change >= 3:1 against the background.

## MEDIUM

6. **R-10 Glass on 7 surfaces.** `backdrop-filter` at `app.css:113, 230, 298, 332, 441, 1319, 2705`. Cap is 1-2.
   Fix: keep it on the topbar (content scrolls under it) and at most one overlay; the rest become solid `--bg-*`. Write the reason in a CSS comment.
7. **R-06 Uppercase, wide-tracked labels.** Table headers (STATUS, TITLE / HOOK, FILE, VIDEO ...: `workspace.src.css` `.ws-row.head` and the clip table `th`),
   Edit home "HOME" and "CONTINUE WORKING", guide TOC title "PANDUAN" (`guide.css:13`, `.13em`). 9 `text-transform: uppercase` rules in CSS.
   Fix: sentence case, small semibold, no extra tracking. Keep uppercase only where it marks real data (none found).
8. **R-01 Page-wide accent glow.** `app.css:41-42` paints two radial gradients (accent 13%) behind the whole app. No written reason in the direction.
   Fix: remove, or write one line of purpose next to it. Recommend remove.
9. **R-12 Every panel floats.** `.ws-panel` and `.ws-dialog` both carry `--shadow-card`; 23 `box-shadow` rules in `app.css`.
   Fix: panels sit flat (border or bg step only); shadow stays on things that really lift: dialogs, popovers, menus.

## LOW

10. **R-05 / C-3 Table columns crush the deciding field.** Sources: VIDEO name shows 4-5 characters ("Agak...", "C8 P...") while Used by and
    Credit take the width, and every row has a full Delete button. Workspace clips: Title / hook ~10 characters at 800px.
    Fix: name/title get `minmax(180px, 2fr)`; Used by and Credit shrink first; Delete becomes the compact quiet style used for "View"/"Detail".
11. **Guide TOC breaks around parentheses.** `guide.html:58` puts two links and "( )" in one `li`, and `.guide-toc a { display: block }`
    renders "(" and ")" on their own lines. Fix: make "Batas upload" its own `li`.
12. **R-23 Profile avatars all read "K".** The three profiles all start with "klipian", so every avatar shows the same letter.
    Fix: take the initial from the word after "klipian" (I, L, P), or the first letter that differs.

13. **R-11 / C-4 Sources row checkboxes are not aligned (ian reported).** The new select boxes (`sources.js:78` head, `:98` rows,
    still uncommitted) sit inside the `.name` label, so they take the browser default size and margin, sit on the text baseline
    instead of the row centre, have no accent colour, and get cut by the name's ellipsis. Deleted rows have no box, so their names
    start ~20px further left than live rows. The Clips table already solves this (`pager.css:97-107`: 16px, margin 0, centred, accent).
    Fix: give the box its own first grid column (`24px` added to `.ws-row.sources` in `workspace.src.css`, rebuild `workspace.css`),
    head select-all in that column, an empty cell for deleted rows, and the same 16px / margin 0 / `accent-color` / centred rule as
    `#clipTable`. Keep the `@media (max-width:900px)` layout working (box stays beside the name). Keep the aria-labels.

## Human pass (antislop-human, added later on 2026-11-06)

Method: a script in the live pages (5177, read-only) measured every visible text pair (WCAG formula, alpha blended onto the real

Note: /execute was already editing, so pages served the half-done tree (finding 1's status colours already pass in light).

14. **HIGH R-25 Light theme: faint and accent text just under 4.5:1.** `--text-faint` (light `oklch(.545 .016 258)`) on cards/panels:
    project card meta 4.03, eyebrow 4.37, remotion hints/chips 4.37, guide footer 4.37, guide `kbd`/`code` 3.74.
    Accent used as text (`oklch(.55 .145 75)`): guide links 4.40, remotion selected "45 detik" 4.13. "last opened" badge 3.99.
    Fix: darken the light values of `--text-faint` (~.49) and of the accent when used as text (~.48) in BOTH light blocks of
    `tokens.css` (the `prefers-color-scheme` block ~line 100 and the `[data-theme=light]` block ~line 149), and the badge colours.
    Verify each pair >= 4.5:1 on `--bg-1`, `--bg-2`, `--bg-3` with `python C:/Users/user/.claude/skills/antislop-human/contrast-check.py`.
    Dark theme passed everywhere.
15. **HIGH R-39 Clip table inputs have no accessible name.** Each row's title, date, time inputs and status, platform selects
    (`clips.js` row template) have no label or aria-label; a screen reader says "edit text". Fix: `aria-label="Title"`, "Upload date",
    "Upload time", "Status", "Platform" (plus the clip title, e.g. `aria-label="Status: ${title}"`).
16. **HIGH R-39 Controls without `cursor: pointer`.** Sources row and select-all checkboxes, the pager "Rows per page" select (every
    page), a remotion checkbox, and the Edit topbar brand button `#toHome`. Fix once in the base layer in `brand.css` (loaded by every
    page): `button:not(:disabled), select:not(:disabled), summary, label[for], input[type=checkbox]:not(:disabled),
    input[type=radio]:not(:disabled), [role=button]:not([aria-disabled=true]) { cursor: pointer; }`.
17. **LOW R-32 The accent focus ring exists only on the Edit page.** The global `:focus-visible { outline: 2px solid var(--accent) }`
    is in `app.css:955`, which only `index.html` loads. On workspace, sources, remotion, guide and profiles, links, nav, profile chip,
    checkboxes and sort headers fall back to the browser's thin default ring (Tab test on /workspace). Fix: move that rule to
    `brand.css` so every page has the same visible ring.

Human pass, checked and passing: no icon-only button without a name, no image without `alt`, no clickable div/span (the
`role="button"` icons and project cards have Enter/Space handlers), Escape handlers on menus and dialogs, `role="status"` regions
for progress notes, statuses carry text not colour alone, global reduced-motion rule.
