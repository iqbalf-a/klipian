Panduan klipian

Halaman ini statis: tidak ada data profile di sini. Nama menu ditulis persis seperti di Google Cloud console (2026) dan di klipian, supaya bisa diikuti langkah demi langkah.

A. YouTube: satu project Google Cloud per channel

Kenapa satu project per channel. Kuota unggah YouTube Data API dihitung per project Google Cloud: yang kami ukur adalah 100 unggahan per hari per project. Kalau semua channel memakai satu project, kuotanya dibagi. Project terpisah juga memisahkan token, jadi satu channel yang bermasalah tidak mengganggu yang lain.

Tidak perlu menagih apa pun. Jangan klik Try for free atau mengisi billing: YouTube Data API v3 gratis dalam kuota ini.

1. Buat project

  1. Buka console.cloud.google.com dengan akun Google tempat kamu mengelola semua project klipian. Akun ini tidak harus pemilik channel: pemilik channel cukup didaftarkan sebagai Test user (langkah 4).
  2. Klik pemilih project di bar atas (Select a project) › New project.
  3. Beri nama, misalnya klipian-lucu, lalu Create. Pastikan project baru itu yang terpilih di bar atas.

2. Aktifkan YouTube Data API v3

  1. APIs & Services › Library.
  2. Cari YouTube Data API v3 › Enable.
  3. Cek kuotanya: APIs & Services › Enabled APIs & services › YouTube Data API v3 › Quotas & System Limits, lihat baris Video Uploads per day.

3. Layar persetujuan (Google Auth Platform)

  1. Buka Google Auth Platform › Get started.
  2. App name: bebas (misalnya klipian). User support email: emailmu.
  3. Audience: pilih External.
  4. Contact information: emailmu. Setujui kebijakan, lalu Create.

Menu di kiri sekarang: Overview, Branding, Audience, Clients, Data Access.

4. Test user: akun pemilik channel ini

  1. Audience › bagian Test users › Add users.
  2. Isi akun Google yang memiliki channel ini, lalu Save.

Kalau akun itu tidak ada di daftar, Google menolak masuk dengan pesan “belum diverifikasi / akses diblokir”. klipian menampilkannya sebagai Not a test user (merah).

5. Data Access: izin yang dibutuhkan

  1. Data Access › Add or remove scopes.
  2. Centang …/auth/youtube.upload dan …/auth/youtube.readonly (kalau tidak tampil di daftar, tempel di kolom Manually add scopes › Add to table).
  3. Update, lalu Save.

6. Client (Desktop app) dan file JSON

  1. Clients › Create client.
  2. Application type: Desktop app. Nama bebas. Biarkan kotak AI-powered agent tidak tercentang.
  3. Create, lalu klik Download JSON saat itu juga: rahasia (secret) client bisa jadi hanya ditampilkan sekali.
  4. Simpan file itu di tempat aman, misalnya folder pribadimu. Namanya biasanya client_secret_….json.

Jangan bagikan file JSON itu dan jangan ditempel di chat, email, atau repo. Siapa pun yang memegangnya bisa memakai kuota project-mu. klipian hanya menyimpannya di folder profile ini.

7. Hubungkan di klipian

  1. Buka profile channel yang benar (nama dan warna profile tampil di pojok atas).
  2. Profile settings › bagian YouTube account › Choose client_secret.json… › pilih file tadi. Baris Client menjadi hijau (Client ✓).
  3. Connect YouTube. Browser terbuka: masuk dengan akun pemilik channel ini, pilih channel yang benar kalau ditanya, lalu izinkan.
  4. Baris Account menjadi hijau: Connected ✓ dengan nama channel. Selesai.

Status Testing dan audit

  • Testing = sambung ulang tiap kira-kira 7 hari. Selama project berstatus Testing, token Google kedaluwarsa sekitar tujuh hari. klipian menandainya Expired (kuning): tekan Connect again.
  • Unggahan dari project yang belum diaudit dikunci private. YouTube menahan video yang diunggah lewat API dari project yang belum lolos audit menjadi privat (“locked private”). Jadi video-nya sampai, tetapi kamu perlu mengubah visibilitasnya sendiri di YouTube Studio, atau mengajukan audit YouTube API Services supaya unggahan publik diizinkan. Jadwal publikasi dari klipian tidak mengubah ini.

B. Status dan arti warna

Di Profile settings › YouTube account ada dua baris, dan titik kecil di samping nama profile memakai warna yang sama.

Baris Client (file client_secret.json)

Client ✓
File valid. Project Google Cloud yang dipakai ditampilkan, dan apakah dari profile ini atau cadangan bersama (workspace/secrets).
Client ✕
Bukan client_secret.json yang bisa dipakai (salah jenis client, file rusak). Pilih lagi; harus Desktop app (bagian 6).
Client
Belum dipilih. Choose client_secret.json…

Baris Account

Connected ✓
Tersambung dan token diterima. Hijau penuh hanya kalau baris Client juga hijau.
Not connected
Belum ada tautan. Pilih client dulu, lalu Connect YouTube (bagian 7). “No client yet” artinya file client belum dipilih.
Expired
Sambungan kedaluwarsa (project berstatus Testing: sekitar 7 hari). Tekan Connect again.
Other channel
Token sah tetapi milik channel lain dari yang tersimpan. Connect again untuk menerima channel baru, atau masuk dengan akun yang benar.
Not a test user
Google menolak masuk: tambahkan akun itu di Google Auth Platform › Audience › Test users (bagian 4), lalu Connect lagi.
Offline
Google tidak terjangkau; status terakhir yang diketahui ditampilkan. Coba lagi saat internet kembali (Check connection).
Paket YouTube belum terpasang
Jalankan sekali: .venv\Scripts\python.exe -m pip install -r requirements-youtube.txt

C. Claude API (Find clips with Claude)

Opsional. Tanpa ini semuanya tetap jalan: Copy brief atau Download file di layar Analyze, tempel ke Claude di web, lalu tempel jawabannya lagi di klipian. Cara manual itu tidak butuh key.

Memasang key

  1. Buka console.anthropic.com › API Keys › buat key. Akun harus punya kredit (isi saldo di Billing), kalau tidak panggilan ditolak.
  2. Pasang paketnya sekali: .venv\Scripts\python.exe -m pip install -r requirements-claude.txt
  3. Di klipian: Profile settings › Anthropic API › tempel key › Save key › Test. Key disimpan di server lokal dan tidak pernah dikirim ke browser lagi. Jangan menempelnya di chat atau repo.
  4. Pilih Model (bawaan: Opus terbaru di akunmu) dan Effort. Tabel di bawahnya menunjukkan pemakaian per bulan.

Memakainya

  1. Di layar Analyze, tekan Find clips with Claude.
  2. Dialog menampilkan model, jumlah token masuk, dan perkiraan biaya sebelum apa pun dikirim. Itu perkiraan: token berpikir dan jawaban baru diketahui setelah selesai.
  3. Tekan Send to Claude. Hasilnya masuk seperti impor manual (saran AI di layar Clips). Cancel menghentikannya.

Rubrik yang dipakai (dialog, gameplay, atau rubrik sendiri di workspace/rubrics) dipilih di Profile settings, atau per brief di layar Analyze.

D. Unduh dari YouTube

Di layar Assets (atau Analyze) pilih Add from YouTube, tempel satu tautan video, Check, lalu Download. Berkas masuk ke folder sources profile dengan nama “channel - judul.mp4” dan kreditnya terisi otomatis.

Yang dibutuhkan

  1. yt-dlp: .venv\Scripts\python.exe -m pip install -r requirements-download.txt (memasang yt-dlp[default]). YouTube sering berubah: kalau unduhan gagal, tekan Update yt-dlp di dialog.
  2. Node.js (atau deno) di PATH, dari nodejs.org. Tanpa runtime JavaScript, YouTube menolak unduhan panjang (HTTP 403). Dialog menampilkan runtime yang dipakai di sebelah versi yt-dlp; kalau tertulis “no JS runtime”, pasang Node.js lalu Update yt-dlp.
  3. ffmpeg (sudah dibutuhkan klipian) untuk menggabungkan video dan suara.

Tips

  • Video 83 menit pada 1080p bisa sekitar 1,8 GB. Pilih 720p (smaller) di kartu pratinjau kalau ruang atau waktu terbatas; ukurannya diperbarui.
  • Kalau gagal, pesan ramah ditampilkan dengan baris kecil berisi error aslinya dan tombol Copy details. Salin dan kirim itu kalau perlu bantuan. Lognya juga ada di ytdl.log di folder profile.
  • Video privat, berbatas umur, atau khusus member tidak bisa diunduh: klipian tidak masuk (sign in).

Kredit bukan izin. Mengisi kredit sumber hanya memberi atribusi; itu tidak memberimu hak memakai ulang video orang lain. Unduh hanya konten yang boleh kamu pakai.

E. Profile dan Guest

  • Satu profile = satu channel. Masing-masing punya sources, project, hasil render, jadwal unggah, akun YouTube, dan pengaturan (watermark, rubrik, hashtag) sendiri. Rubrik buatan sendiri dan cache transkrip dipakai bersama semua profile.
  • Profile dipilih per tab browser: dua tab bisa memakai dua channel sekaligus. Nama dan warna profile selalu tampil di pojok atas supaya tidak salah channel. Tidak ada password: klipian jalan di komputermu dan profile hanya memisahkan data.
  • Membuat profile baru: halaman pemilih profile › Profile baru (nama, warna). Lalu pilih rubrik di Profile settings, hubungkan YouTube (bagian A).
  • Guest: untuk mencoba cepat. Bisa mengedit, merender, mengunduh dari YouTube, dan memakai Find clips with Claude (key-nya disimpan di workspace, dipakai bersama semua profile; mengaturnya dari profile biasa). Tidak punya jadwal unggah, akun YouTube, atau pengaturan. Clear guest data di menu profile menghapus semua buatan Guest ke Recycle Bin.

F. Render massal

Layar Clips membaca dari atas ke bawah:

  1. Choose moments: centang saran AI di daftar. Lalu pilih salah satu dari dua jalan:
    • One video from these moments (Add N to this Result): saran yang dicentang digabung ke Result yang terbuka. Satu render = satu file.
    • A separate video for each (Make N separate Results): tiap saran menjadi Result sendiri dan mewarisi format output Result yang terbuka. Render = N file.
  2. Results: daftar klip yang akan dirender. Tiap baris menunjukkan durasi, format output, framing, dan kapan terakhir dirender. Tick = ikut Output format / Delete / Render; Editing = Result yang sedang terbuka di bawahnya. Pilih cepat: Select all from this brief, All, None.
  3. Output format…: satu format (Picture, Background, Position, Resolution, Quality) untuk semua Result yang dicentang, dengan pratinjau satu klip contoh. “Keep each Result's own” membiarkan satu kontrol tetap seperti aslinya, jadi misalnya hanya Picture yang diubah.
  4. Render selected (N): dialog rencana menampilkan tiap klip beserta formatnya, perkiraan waktu, dan opsi AI Framing untuk klip tanpa framing. Hasilnya ada di layar History.

Upload massal ke YouTube (di Workspace, centang klip, Upload to YouTube) punya dua mode: Schedule (bawaan: tiap klip tayang pada tanggal dan jamnya) dan Publish now: semua video yang dipilih langsung publik satu per satu begitu selesai diunggah, tanpa tanggal. Mode ini selalu dimulai dari Schedule, memberi peringatan, dan meminta konfirmasi; dari klipian tidak bisa dibatalkan setelah tayang. Short yang tayang bersamaan cenderung saling bersaing, jadi menjadwalkannya dengan jeda biasanya lebih baik.

Delete selected dan ✕ di tiap baris menghapus Result (ada Undo beberapa detik). Berkas yang sudah dirender dan baris jadwal unggah tidak pernah ikut terhapus.

Framing otomatis (titik 00:00 yang belum disentuh) memakai tinggi penuh video dengan lebar sesuai bentuk gambar, di tengah. Titik yang kamu atur sendiri tidak berubah.

G. Teks posting untuk satu klip (tanpa API key)

Untuk klip yang kamu potong sendiri (momen diketik tangan) atau Result mana pun: judul Result, judul unggahan, caption, hashtag, dan sudut pandang bisa ditulis Claude lewat chat, cukup salin dan tempel. Tidak perlu API key dan tidak ada biaya selain langgananmu.

  1. Buka layar Render dengan Result yang dimaksud, panel Post text, bagian Write it with Claude.
  2. Tekan Copy brief for this Result (atau Download). Isinya singkat: kata-kata klip ini saja (sudah dengan koreksi, waktunya dihitung dari awal klip), sinyal suara di dalamnya, konteks sumber, bagian rubrik Judul dan hook, Teks posting, dan Sudut pandang, aturan hashtag profile, dan bentuk jawaban. Rubrik yang dipakai: pilihan profile, atau pilihan di layar Analyze.
  3. Tempel ke Claude di web (chat baru) dan kirim.
  4. Salin jawabannya, lalu di klipian tekan Paste reply… dan tempel. Pesan Claude utuh boleh: blok JSON-nya dicari sendiri, dan salah ketik yang umum (koma di ujung, .replace) diperbaiki dan diberi tahu.
  5. Kolom yang terisi: judul Result (nama di daftar dan nama berkas), Post text (judul, caption, hashtag), dan Angle (take, intro, notes). Kalau sebagian sudah ada isinya, klipian bertanya Replace what is written? dengan daftar kolomnya. Undo mengembalikan semuanya.

Di mana tombolnya: di panel Post text (paling atas, layar Render); di layar Clips tiap baris Results menunjukkan post ✓ judul atau no post text dan punya tombol Post text…; panel Open Result punya Write post text with Claude; dan untuk beberapa Result sekaligus, centang barisnya lalu Write post text… di bar bawah daftar: satu brief berisi semua Result yang dicentang (tiap klip dengan id-nya) dan Claude menjawab dengan satu entri per id. Kolom yang sudah terisi ditanyakan per Result, dan satu Undo mengembalikan semuanya.

Kalau jawaban kurang satu kolom, pesan menyebut yang mana (misalnya post.caption): minta Claude menjawab lagi dengan blok JSON lengkap. Judul akhir yang lebih dari 100 karakter diberi peringatan seperti biasa. Kalau Result itu sudah pernah dirender, baris jadwal unggahnya memakai teks baru pada render berikutnya. Panel ini tidak ada untuk profile Guest.
