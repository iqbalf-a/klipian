# antislop UI audit 003: konsistensi bentuk (2026-11-17)

Mode: After. Belum ada yang diubah; perbaikan menunggu nomor yang disetujui ian.

Cakupan: semua halaman `ui/` (profiles, Edit `/`, workspace, sources, remotion, autopilot, guide) dan
semua `ui/css`. Fokus: konsistensi radius, tinggi kontrol, ukuran huruf, kotak (permintaan ian: "radius
button atau box seperti tidak konsisten").

Cara cek: nilai *computed* di halaman hidup (server 5177, profile klipian-intip, hanya dibaca, lebar
1280) untuk setiap tombol, input, select dan kotak bertepi, ditambah grep CSS.

Tidak dicek: `/admin` (di tab uji halaman itu jatuh ke pemilih profile, jadi yang terukur adalah
pemilih profile), layar editor di dalam project (tinggi kontrolnya tidak terukur karena tersembunyi;
radius dan ukuran hurufnya terukur), tema terang, dan tampilan visual lewat screenshot (gagal diambil).

Arah: memory "klipian UI style" (acuan = tombol dan kotak ringkas bertepi di /workspace, tanpa tombol
pill) dan override yang dicatat audit 001 (segmented nav berbentuk pill adalah saklar, bukan tombol).

Prioritas: Hard Gate = TINGGI, Purpose-Gate = SEDANG, Quality Locks = RENDAH.

## Inti masalah

UI punya **dua keluarga bentuk** yang hidup berdampingan:

| | Keluarga /workspace (acuan) | Keluarga Edit (`app.css`, lebih lama) |
|---|---|---|
| Tombol | 4px | 4px, 10px, 14px, pill |
| Input dan select | 4px | pill, 10px, 14px |
| Kotak | 10px, 14px | 10px, 14px, 20px |

Token radius hanya empat (`--r-s` 10, `--r-m` 14, `--r-l` 20, `--r-pill`), tetapi nilai yang benar-benar
tampil ada **sebelas**: 0, 2, 3, 4, 5, 6, 8, 10, 14, 20, 999. Radius yang paling banyak dipakai tombol
(4px) justru tidak punya token.

## SEDANG

1. **R-11 Radius tombol tidak punya satu nilai.** Terukur:
   - `.btn`, `.btn.sm`, `.btn.main`, `.delete-btn`: 4px (semua halaman)
   - `.pager-btn`, `.pager-num`, dua tombol ikon topbar: 6px
   - `.profile-chip-btn` (topbar), `.step-btn`, `.toggle`, `.rm-item`: 10px
   - `.tab` (Edit): 14px
   - `.chip`, `.format-choice` (40 buah), `.result-trigger` (6), `.side-collapse`: pill
   Catatan: `.profile-chip-btn` diperbaiki 9 Nov supaya "sama dengan `.btn`", tetapi diberi `--r-s`
   (10px) sedangkan `.btn` 4px, jadi tetap beda.
   Perbaikan: tambah token `--r-xs: 4px` untuk semua kontrol; tombol di atas memakainya.

2. **R-11 Tombol pill masih ada di halaman Edit.** `.chip` (`app.css:249`), `.format-choice`
   (`app.css:739`), `.result-trigger` (`app.css:2710`), `.side-collapse` (`app.css:1321`). Ini melanggar
   "no pill buttons". Yang BUKAN temuan: `.subtab` dan `.yt-mode-opt` (saklar segmented, override audit
   001), `.yt-badge`, `.ws-gone-tag`, bar progress dan meter (label dan bar, bukan tombol).
   Perbaikan: empat kelas itu memakai `--r-xs`.

3. **R-11 Input dan select punya lima radius.** Terukur:
   - `.ws-input` (workspace, sources, remotion): 4px
   - `select` polos di pager, field autopilot (`apAi`, `apTpl`, `apUrls`), `newName`: 6px
   - `.input`, `.asset-select`, `.result-select` (Edit, 8 buah): **pill**
   - field post dan angle (`postTitle`, `postCaption`, `postTags`, `angleTake`, `angleIntro`),
     `selStart`, `selEnd`, `resultTitle`: 10px
   - `.paste` (4 buah): 14px
   Perbaikan: semua field `--r-xs`, sama dengan tombol di sebelahnya.

4. **R-11 Kotak dan panel: tiga token ditambah nilai liar.** Panel Edit (`.panel`, `.side`, `canvas`,
   `preview`, 28 buah) 20px; dialog dan menu 14px di semua halaman; kotak kecil 10px. Itu masih satu
   skala. Yang di luar skala: `.admin-card`, `.adm-sub`, catatan `.note`/`.warn` di guide, `.rm-video`,
   `.ws-cutnote` (8px); `.guide-toc a`, `.ap-chip`, kotak profile settings (6px); `code` di guide (5px);
   thumbnail (4px dan 6px).
   Perbaikan: 8px dan 6px pada kotak menjadi `--r-s`; thumbnail dan tag kecil menjadi `--r-xs`.

5. **R-11 `border-radius` ditulis sebagai angka di 44 tempat**, bukan token (6px 20 kali, 2px 8, 8px 5,
   4px 5, 3px 4, 5px 2, 10px 1), dan 8 tempat memakai token dengan cadangan yang salah
   (`var(--r-m, 12px)`, `var(--r-m, 10px)`, `var(--r-m, 8px)`: tokennya 14px). Inilah sebabnya nilai
   terus menyimpang setiap ada halaman baru.
   Perbaikan: setelah nomor 1 sampai 4, tidak ada angka radius di luar `tokens.css` kecuali bar tipis
   (2px, 3px) dan lingkaran (50%).

## RENDAH

6. **R-20 Tinggi kontrol dalam satu baris tidak sama.** Terukur di /workspace dan /remotion: tombol
   27px, tombol utama 29px, pager 25px, chip profile 28px, kotak cari 30px, input dan select 32px,
   select pager 28px. Tombol dan input yang bersebelahan selisih 5px.
   Perbaikan: satu tinggi kontrol (mis. 28px) untuk tombol, input dan select; `.btn.sm` tetap 21px.

7. **R-06 Ukuran huruf: 20 nilai untuk 9 token.** Token `--t-10 … --t-29` ada, tetapi CSS menulis angka
   langsung: 13px (43 kali), 12px (35), 12.5px (27), 11px (26), 11.5px (23), ditambah 9, 10.5, 13.5,
   15.5px. Tiga nilai setengah piksel (11.5, 12.5, 13.5) tidak terbedakan mata dari tetangganya.
   Perbaikan: 11.5 menjadi 11 atau 12, 12.5 menjadi 12 atau 13, lalu pakai token.

8. **R-20 Beberapa kontrol tidak mewarisi huruf UI.** Ukuran 13.33px dan 16px adalah bawaan browser,
   artinya elemen itu tidak diberi gaya: `notifySound`, `ytQuality`, `briefRubric` (select), `newName`,
   `slider-number`, 12 `<button>` polos di Edit, `.cue-info`, `.side-collapse`, `.rm-item`.
   Perbaikan: `font: inherit` pada `button, input, select, textarea` di `brand.css` (satu baris).

9. **R-12 Tebal garis tepi campur.** Sebagian besar tombol bertepi 1px, tetapi tombol ikon topbar,
   `.delete-btn`, `.ws-close`, `.tab` dan `.subtab` tanpa tepi. Untuk tombol ikon ini wajar; `.tab`
   bertepi hanya saat aktif (1 dari 9), yang membuat lebarnya bergeser 1px saat dipilih.
   Perbaikan: `.tab` selalu bertepi 1px, transparan saat tidak aktif.

## Skala yang diusulkan (untuk nomor 1 sampai 5)

| Token | Nilai | Dipakai untuk |
|---|---|---|
| `--r-xs` (baru) | 4px | tombol, input, select, chip, tag, thumbnail |
| `--r-s` | 10px | kotak kecil, baris kartu, catatan |
| `--r-m` | 14px | dialog, menu, kartu |
| `--r-l` | 20px | panel utama halaman Edit |
| `--r-pill` | 999px | hanya saklar segmented, label status, bar |

Risiko: nomor 2 dan 3 mengubah tampilan halaman Edit paling banyak (chip dan input pill menjadi
persegi bersudut 4px). Itu memang tujuannya, tetapi lihat dulu hasilnya di salinan sementara (port
5178) sebelum dipakai.
